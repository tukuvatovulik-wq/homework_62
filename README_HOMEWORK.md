# Трекер — продолжение задания

В этой версии добавлены реализации регистрации, владельца/участников проекта и проверок ролей.

## Запуск в Windows
1. Создай виртуальное окружение: `py -m venv venv`
2. Активируй: `venv\Scripts\activate`
3. Установи зависимости: `pip install -r requirements.txt`
4. Применить миграции: `py manage.py migrate`
5. Создать группы и пользователей: `py manage.py setup_roles`
6. Создать администратора (по желанию): `py manage.py createsuperuser`
7. Запуск: `py manage.py runserver`

Пользователи: manager/manager, lead/lead, dev/dev. Команда setup_roles добавляет роли и разрешения.

**Важно:** автоматические Django tests и миграции не удалось запустить в среде подготовки: Django отсутствует, а сеть для установки пакета недоступна.
