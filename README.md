# Домашнее задание №59 — Трекер проектов и задач

Проект создан на основе ДЗ №58.

## Установка

```cmd
py -m venv venv
venv\Scripts\activate
py -m pip install -r requirements.txt
```

## Миграции и демонстрационные данные

```cmd
py manage.py migrate
py manage.py loaddata tasks
```

Фикстура содержит проекты, типы, результаты и задачи. Если фикстура загружается в пустую базу после `migrate`, она создаёт демонстрационные данные.

## Запуск

```cmd
py manage.py runserver
```

Главная страница — список проектов.

## Проверки

```cmd
py manage.py check
py manage.py test
py manage.py makemigrations --check --dry-run
```

## Реализовано по ДЗ №59

- Модель Project и связь Task с Project.
- Миграция создаёт проект и связывает с ним существующие задачи, после чего связь становится обязательной.
- Список проектов на главной странице, поиск по названию и описанию, пагинация по 5 проектов.
- Просмотр, создание, редактирование и удаление проектов.
- Создание задачи внутри выбранного проекта.
- DetailView, UpdateView и DeleteView для задач.
- Мягкое удаление задач через `is_deleted`.
- Обновлённая фикстура `tasks`.


## Аутентификация (ДЗ №61)

- Вход доступен по адресу `/accounts/login/`.
- Выход выполняется кнопкой в меню (POST-запрос).
- Создание, редактирование и удаление проектов и задач доступны только вошедшим пользователям.
- Просмотр списка, проектов и задач остаётся доступным без входа.

Создайте пользователя для входа:

```cmd
py manage.py createsuperuser
```

Затем войдите на сайте под созданным логином и паролем.
